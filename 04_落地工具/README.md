## 落地三路径（摘要，详见矩阵 5.7.5）

- **路径 A（推荐·零成本自动）**：GitHub Actions 定时 → 每周一 08:00 生成"热榜 + AI 工具日报"推送（cron：`0 0 * * 1`）
- **路径 B（本机）**：crontab/launchd 每周触发脚本：拉 RSS → LLM API 摘要 → 情报速递文档；双周跑工具监控
- **路径 C（零部署）**：手机日历人工提醒——**先跑两周验证价值，再上 A/B**

## 可直接用的开源项目速查（详见矩阵第四章）

- RSS/聚合类：FreshRSS / Miniflux / RSSHub / yarr（自建多源订阅）
- 变化监控类：changedetection（XPath 精确监控点，可拆模块）
- 抓取→AI 消化管道类：Horizon（抓取→AI 评分→去重→日报，思路可抄）
- 中文社媒分层类：TrendRadar（热榜分层，思路可抄）
- 定时任务+LLM 工作流：n8n / Dify / daily-digest 类
- 爬虫底座：Playwright / Scrapy / Crawlee

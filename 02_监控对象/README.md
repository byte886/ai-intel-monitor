## 竞品与开源项目（矩阵第四章）

开源监控项目按**三档价值**评估（不是只看能不能部署）：
1. **直接用**：可自托管部署（标注难度）
2. **部分用/可改造**：拆某模块复用（抓取器/摘要流程/定时模板）
3. **思路借鉴**：监控源组织、信息消化（评分+去重+分级摘要）、推送机制、优先级标注、沉淀成库——**设计思路比代码更值钱**

具体项目清单与"4.8 设计思路清单"（7 条可抄思路）见矩阵第四章。

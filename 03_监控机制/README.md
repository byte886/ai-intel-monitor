## 定时更新机制（通用抽取版）

来源：矩阵 5.7（唯一权威源）。要点：

**频率分层**：
- 热搜话题/案例 = 每周
- AI 工具上新与价格 = 双周（核对价格数字/页面API双形态/链接可用性）
- 渠道/平台规则 = 月度（抽检入口 URL 是否 404、关键词热度复核）
- 谷歌/搜索算法 = 事件驱动 + 月度核对
- 竞品/开源 Release = 事件驱动（GitHub Watch→Releases 邮件）
- 展会赛事日历 = 季度核对

**变化检测信号（7 类）**：①平台改版/规则公告 ②工具下架改名涨价≥20% ③Product Hunt 上榜/Toolify 连续两周新工具 ④GitHub Release ⑤行业媒体 AI 珠宝大事件 ⑥搜索算法更新新闻 ⑦入口 URL 404。

**更新后沉淀**：矩阵对应行标复核时间 → 影响选型则写回选型文档 → CHANGELOG.md 编年体记一条（`YYYY-MM-DD ［类型］一句话`，类型=新增/变更/修复/废弃/移除）→ 未核实进 ISSUES.md。

**落地三路径**：A GitHub Actions 定时（零成本自动，cron 如 `0 0 * * 1`）｜B Mac crontab/launchd 本地脚本（采集+摘要，筛选仍人工）｜C 手机日历人工提醒（**先跑两周验证价值再决定上 A/B**）。

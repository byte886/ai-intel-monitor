# 每周扫描操作卡（各平台方法速查）

> 来源：矩阵 v1.1 §5.1（25 工具清单）+ §5.2（每周扫描清单）提炼，2026-10-06。用途：执行《每周情报速递》时照此操作。**发现层（本卡）≠ 深度解析层（multiplatform-media-fetch 技能）**——发现层用搜索+热榜+趋势工具记选题；深度层用于解析具体视频内容/收藏遍历。

## 一、各平台扫描方法

| 平台 | 发现层方法（本卡） | 深度解析层（技能） | 需代理/登录 |
|---|---|---|---|
| **抖音** | APP/网页搜关键词（关键词库）→ 筛"一周内·最多点赞"挑 3 条记选题；抖音指数 trendinsight.oceanengine.com 看热度+红色上升词；APP 内搜"热点宝"看垂类话题榜 | douyin-favorites-extract（收藏遍历，需 Chrome 登录）/ douyin-browser-extract（页面直读） | 网页免登可搜；收藏遍历需登录 |
| **小红书** | 网页/APP 搜泛珠宝词筛"最热"；创作者中心→笔记灵感（官方选题） | xhs_downloader.py（Playwright，首次扫码登录，cookie 持久化） | 免登可浏览；下载需扫码一次 |
| **B站** | 搜 `#珠宝设计 #AI珠宝设计` 等标签按最新；关注"画珠宝的阿裁"等 UP 主 | 裸 BV 号下载/转写/UP 主投稿列表（skill 原生支持，直连） | 免登 |
| **微博** | 微博热搜蹭点 + 搜珠宝大V（珠宝君Yu东森等） | 无专项（视频解析走抖音/其他） | 免登 |
| **知乎** | 搜"珠宝/翡翠/黄金"按"最多赞同"筛高赞问答=用户真实需求 | 无专项（文章可直接读） | 免登 |
| **视频号** | 搜"翡翠手镯"按"直播中"排序（私域中老年话术借鉴） | 无专项 | 免登（微信生态） |
| **行业媒体** | Inoreader 订阅 JCK / National Jeweler / The Jewelry Wire / Natural Diamonds → 周三扫邮件 | 无 | 收信即可（邮箱） |
| **海外趋势（代理）** | Google Trends / Pinterest Trends / TikTok Creative Center（珠宝类 Top Ads）/ Exploding Topics → 海外组关键词 | YouTube 下载转写（代理+skill） | **需代理**（大陆直连不可用） |
| **热榜聚合** | 今日热榜 tophub.today（无小红书栏）/ 新榜 newrank.cn 珠宝周榜 / 微博热搜 | 无 | 免登 |

## 二、每周节奏（照做）

| 周几 | 平台/工具 | 搜什么/产出 |
|---|---|---|
| 周一 20min | 抖音 | 珠宝营销案例/手串抖音爆款/翡翠视频/AI珠宝 → 记 3 条选题（丢 Raindrop） |
| 周二 15min | 抖音指数 | 3-5 核心词热度曲线+上升关联词 → 下周标签 |
| 周三 10min | 邮箱+Inoreader | JCK/National Jeweler/The Jewelry Wire 邮件 → 有价值文章豆包摘要 1 句 |
| 周四 25min（代理） | Google Trends+Pinterest+TikTok CC+Exploding | 海外组词 → 记 1-2 条"海外在涨国内空白" |
| 周五 20min | 今日热榜+新榜+微博热搜 | 蹭点 → 写进下周选题 |
| 周六 20min | 小红书+Raindrop | 泛珠宝词"最热" + 归档 → 写《每周情报速递》 |
| 每月最后周五 | JCK官网+新榜竞品+关键词库 | 展会/竞品涨粉/关键词复盘 → 月报 |

## 三、工具速查（25 项见矩阵 §5.1，常用 10 项）

Feedly/Inoreader（RSS）｜JCK/National Jeweler 邮件｜百度指数（免费 50 词）｜抖音指数｜今日热榜｜新榜｜Google Trends/Pinterest Trends/TikTok CC（代理）｜Raindrop.io（书签归档）｜Exploding Topics

## 四、已知限制（诚实标注）

- 抖音/小红书**站内无关键词订阅提醒**（已查证），只能定期人工搜——本卡就是固定节奏
- 海外工具（Google Trends/TikTok CC 等）**大陆直连不可用**，需代理；邮箱订阅不受影响
- 视频号深度解析无专项技能（暂以浏览为主）
- 灰豚/蝉妈妈等付费深度数据未购（发现层免费够用）

# 搜索方法论：海量内容中提取有效数据（珠宝监控适用）

> 沉淀自 2026-10-06 调研（Google 搜索操作符清单×8、OSINT 方法论×6、品牌监控布尔查询×5，多源交叉验证）。
> 核心命题：**平台内容海量、全搜不可能；谷歌只看前几页有效。解法不是"翻更多页"，而是"把相关结果压缩到前几页"**。

## 一、总原则：问题驱动，不做全量搜索

OSINT 五阶段（Planning→Collection→Processing→Analysis→Reporting）第一步是**定义情报需求**（Wiz/Freetechlearner）：
> 先问"这周我要回答什么问题"（如：竞品出了什么 AI 新动作？哪个选题在涨？哪个工具降价了？），**每次只搜能回答该问题的 1-3 个查询**，而不是漫无目的全搜。搜索是无止境的，问题驱动才能止损。

## 二、三层压缩策略（把结果压进前 3 页）

### 第 1 层：关键词工程
- **核心词 × 场景词矩阵**：核心词（珠宝/AI珠宝/手串）只回答"是什么"，必须配场景词才有效——例：`珠宝直播` × `门店获客/爆款/案例`；`AI珠宝` × `视频/提示词/模型/成本`
- **同义词组（OR 组）**：同一品牌/概念多种叫法一次搜全——`("周大生" OR "周生生") 手链 AI`
- **排除词（NOT）**：砍噪音——`珠宝直播 -开奖 -福利`（排除抽奖活动贴）
- 依据：Meltwater/YouScan 品牌监控查询构建法（"BrandName" OR "@Handle" OR "Brand Name" 覆盖多形态）

### 第 2 层：操作符体系（Google 27 个操作符中高频 10 个）
| 操作符 | 用途 | 珠宝示例 |
|---|---|---|
| `site:` | 限定站点（垂直搜索，比站内搜索强） | `site:iesdouyin.com 珠宝 直播 案例`；`site:zcool.com.cn 珠宝设计` |
| `intitle:` | 词在标题（高相关信号） | `intitle:珠宝 门店 获客` |
| `inurl:` | 词在 URL | `inurl:jewelry filetype:pdf` |
| `filetype:` | 找报告/文档 | `珠宝 市场报告 filetype:pdf`；`AI 珠宝 filetype:pdf` |
| `"精确短语"` | 必须连在一起 | `"AI珠宝设计"` |
| `OR / \|` | 多词任一 | `(珠宝 OR 首饰) AI 视频` |
| `-` | 排除 | `珠宝 -银饰`（只看黄金） |
| `( )` | 分组 | `(珠宝 OR 翡翠) (直播 OR 带货)` |
| `related:` | 找同类站 | `related:newrank.cn` |
| `A~近义` | 同义词（Google 自动） | `~珠宝 直播` |

> 依据：OSINT.org 明确"操作符驱动搜索仍是最高产出技术；同一查询跑多个引擎（Google/Bing/百度/Yandex），索引差异大"。**我们的 general_search 工具实测支持 site:；部分操作符（filetype:/intitle:）以实际返回为准；完整操作符库建议在 Google 网页用**（需代理）。

### 第 3 层：时间限定
- 关键词带年份/月份：`珠宝 AI 2026`（比工具时间筛选更稳）
- 搜"本周/本月"：Google 工具→时间筛选（工具支持时）；否则用 `2026-10` 类词
- 依据：SOS Intelligence"过时信息会扭曲分析，始终检查发布日期"

## 四、信号 vs 噪音筛选规则（拿到结果后 15 秒/条）

1. **标题检查**：真实数据 vs 标题党——"爆款/火了/疯抢"但无具体数字 → 噪音（降级/淘汰）
2. **时效检查**：发布时间 >30 天且是"行情/价格/案例"类 → 标"背景参考"；方法类可保留
3. **来源分级（对应 L1/L2/L3）**：
   - 官方平台发布（抖音电商学习中心/官网/新闻稿）→ L2 起
   - 权威媒体/一手报告 → L3 候选
   - 博主/服务商/博客自述 → L1，禁决策
   - （对应 OSINT "Admiralty Code"来源可信度分级，SOS Intelligence）
4. **去重**：同一事件多源 → 取一手来源，其余标注"互证"
5. **多引擎交叉**：关键结论用 Google + Bing/百度 各搜一次，索引不同、防单引擎偏置

## 五、前 3 页利用最大化（不翻页策略）

| 情况 | 动作 |
|---|---|
| 结果 <30 条且相关 | 全看，不必翻页 |
| 结果多但前 3 页噪音多 | **不翻页**，回炉改查询（加排除词/加 site:/加时间/换同义词），比翻到第 5 页有效 |
| 某关键词无结果 | 换同义词（珠宝→首饰/饰品；AI→人工智能/智能设计），或拆短（去修饰词） |
| 需要权威文件 | 直接 `filetype:pdf` + 官网 `site:`，跳过网页噪音 |
| 站内收录少（小红书） | 换技能登录路线（xhs_downloader），不硬搜 |

## 六、与监控体系衔接

```
每周扫描（操作卡）→ 用本节查询模板出"候选"
  → 速递标 L1/L2/L3（两级取证）
  → 任何候选用于生产前：官方工具核热度（抖音指数/新榜/蝉妈妈）+ 原页精读
  → 升级 L2/L3 才进决策流
```

## 七、验证与更新

- 本方法论每季度复核一次：操作符是否仍有效（搜索引擎会变）、查询模板是否覆盖新问题
- 查询模板随关键词库更新（月度）
- 每条模板的"实测可用性"在执行时记录（哪个操作符在哪个工具不生效，回写本节）

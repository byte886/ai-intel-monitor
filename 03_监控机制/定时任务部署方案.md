# 定时任务部署方案（B1 · 待验证后升级）

> 状态：**人工驱动验证中**（2026-10-06 用户拍板：先由用户告知触发，验证情报流价值后再考虑自动化）。本文件记录频率方案与推送渠道对比，供后续升级参考。

## 一、频率方案（业界多源验证）

| 周期 | 任务 | 业界依据 |
|---|---|---|
| **每周一 08:00** | 珠宝AI情报速递：抖音/小红书关键词扫描 + 热榜 + 行业媒体邮件 | ITONICS / Oden / tigertail 均"周度轻量信号层 30min 复核" |
| **双周周五** | AI 工具价格/形态/可用性复核（矩阵三章） | 价格变化快，双周=用户场景特有档 |
| **月度最后周五** | 渠道规则/关键词库/竞品月度核对 | Oden/tigertail："月度深度回顾+趋势报告" |
| **事件驱动** | 定价页变化 / 平台改版 / 工具下架涨价≥20% | ITONICS"盯定价页+社媒情绪"，单店店主改事件驱动+每周兜底 |

> 关键依据（agribusiness playbook "Daily Brief Test"）：日报若 30 天内没人读，问题在路由或信号密度——单店店主周报比日报合适，故不设日更。

## 二、推送渠道三方案对比

| 方案 | 机制 | 优点 | 成本 |
|---|---|---|---|
| **① 豆包工作台定时任务**（推荐起步） | 定时任务技能建 cron，到点触发 AI 执行扫描 → 摘要出现在豆包对话，手机随时看 | 零配置零成本、贴合手机豆包；筛选仍人工 | 免费（豆包会员内） |
| **② GitHub Actions → 邮箱** | 矩阵路径A：fork TrendRadar/Horizon 定时跑 → 推 QQ 邮箱（JCK 邮件同渠道） | 全自动、不依赖豆包 | 需 LLM API Key + Action YAML |
| **③ 本机 crontab** | 路径B：Mac 定时脚本 + LLM API 摘要 | 可控 | 需 Mac 常开、配置脚本 |

## 三、当前决策（2026-10-06）

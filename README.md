# ai-intel-monitor · AI 情报监控体系（通用仓库）

> 面向"持续跟踪、扫描、借鉴"的通用情报监控仓——不限行业。当前首个应用场景：珠宝（线下门店、AI 生成珠宝效果图/视频、抖音主阵地）。

## 这个仓库解决什么问题

渠道会变（谷歌规则、搜索引擎、社媒平台）、AI 工具会变（新模型/价格/上下线）、行业案例会变。本仓库沉淀一套**可复用的监控体系**：

- **渠道矩阵**：国内外"珠宝营销 / 珠宝AI / 泛行业创意"的渠道全景（社媒账号、话题标签、行业媒体、社区、数据工具、展会）——`01_渠道矩阵/`
- **监控对象**：AI 工具（页面/API 双形态、免费/付费）、竞品与开源项目（三档价值：直接用 / 部分用 / 思路借鉴）——`02_监控对象/`
- **监控机制**：定时更新机制（分层频率）、协作策略路由（推派 vs 拉取/黑板认领，可切换）——`03_监控机制/`
- **落地工具**：RSS/定时任务/摘要推送的开源项目清单与组合方案——`04_落地工具/`
- **场景应用**：各行业的落地实例（当前 `场景应用/jewelry/`）——珠宝关键词、渠道实例、落地备注

## 目录约定

- `01_渠道矩阵/`：渠道清单（通用部分）；行业特定渠道放 `场景应用/<行业>/`
- `02_监控对象/`：工具/竞品/开源项目清单（通用结构 + 行业实例）
- `03_监控机制/`：更新频率、变化检测信号、协作策略（跨行业通用）
- `04_落地工具/`：可部署/可借鉴的开源项目、定时任务方案
- `场景应用/<行业>/`：行业专属内容（关键词库、渠道实例、落地备注），指向珠宝仓等主仓的指针放这里

## 运行规则（给 AI）

1. 所有结论来源标注四档：✅已查证（官方一手可回源）/🔶经搜索补充（≥2 独立来源）/🟡一方说法（单源降档）/⚪未经核实（单列清单）
2. 调研多查多看、多源交叉验证；单源不得定论
3. 借鉴创意≠盗用素材：涉及品牌 logo/产品图/版权素材时标注红线
4. 定时更新：按 `03_监控机制/` 分层频率执行；变化未核实时标注待验证，不编造
5. 新行业接入：复制 `场景应用/<行业>/` 模板，按模板补渠道实例与关键词即可

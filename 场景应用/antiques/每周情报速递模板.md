## 填写说明

- **证据档强制**：每条发现标 L1/L2/L3；L1 进第五节待验证队列；L2 以上标注来源链接
- **借鉴≠盗用**：只拆结构/行情/断代知识，不搬拍品图录、藏品、文案
- **交叉不重复**：古瓷行情进 ceramics 视角、玉器进 jewelry 古玩视角，本目录只记杂项器物（鼻烟壶/文房/铜器漆器/竹木牙角）
- 发现新专场/新成交纪录/新鉴定术语 → 当场修订 `关键词库.md` 或本 README 渠道速记，拿不准进 ISSUES.md

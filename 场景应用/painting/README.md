## 书画场景要点（来源：矩阵 v1 §3.6 + 书画包）

- **品类覆盖**：中国艺术品拍卖第一大品类，高净值藏家与珠宝客群同源。四体系——
  - 中国古代书画（嘉德古代夜场 / 故宫·上博馆藏研究）
  - 中国近现代书画（保利 / 荣宝斋，收藏投资主战场）
  - 当代水墨（ART021 / 画廊周）
  - 书法墨迹（西泠印社 / 朵云轩）
- **市场锚点**：嘉德 2025 春拍总成交 16 亿 ✅ https://www.thepaper.cn/newsDetail_forward_30904564 ；保利 2025 春拍书画板块 +74.5%、傅抱石《柳溪仕女》2415 万 ✅ http://epaper.zqrb.cn/html/2025-10/18/content_1189493.htm
- **主阵地（主渠道速记）**：**雅昌艺术网** + **嘉德·保利官网**（拍场成交第一落点）；鉴伪舆情在**抖音鉴宝 + 知乎**；当代水墨在**小红书 + B站 + Instagram + Artsy**
- **高价值渠道速记**：
  - 拍场成交/行情：**雅昌艺术网**（拍卖图录/AMMA）/ **嘉德·保利官网**（拍行官方公众号）；海外 Sotheby's/Christie's 官网
  - 鉴伪/藏家讨论：**抖音鉴宝** + **知乎**（长文深）；海外 Reddit **r/ChineseArt**（华人藏家长讨论）；小红书收藏圈
  - 当代水墨生态：小红书 + B站 + Instagram + **Artsy**；ART021/画廊周
  - 书法墨迹：西泠印社 / 朵云轩

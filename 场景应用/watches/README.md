## 腕表场景要点（来源：矩阵 v1 §3.7，行业特定部分）

- **品类覆盖**：四体系——瑞士高级制表（劳力士/百达翡丽/爱彼）/ 独立制表（F.P.Journe/GPHG/Only Watch）/ 德日表（Grand Seiko）/ 古董表·怀表（拍行钟表部）；监控主对象是**二级市场（二手表回收·行情）**，与珠宝共享"鉴定-回收-保值"叙事
- **市场锚点**：2025 国内腕表回收约 491 亿、CAGR~30.5% 🔶 https://finance.sina.com.cn/tjhz/2026-09-15/doc-inirwmwe3680394.shtml.md ；2026H1 全球二手腕表 105 亿美元 +37.2% 🔶（同源，行业包 §watches 待验证项登记）
- **主阵地**：腕表之家+得物（二级行情核心）；抖音（表商报价直播）；X（实时报价/日本表圈）；Reddit（r/Watches 鉴定讨论）
- **高价值渠道速记**：
  - 二级行情：腕表之家、得物、Chrono24、WatchBox（二级市场数据化程度高，价格透明可追踪——矩阵 §二）
  - 顶级拍场：Phillips 钟表部、Sotheby's 钟表部（拍卖中心在日内瓦/香港）；国内转报走雅昌+微信拍行公众号
  - 讨论场：知乎（鉴定长文）、Reddit（r/Watches）、X（实时报价）
  - 独立制表风向：GPHG（日内瓦钟表大赏）、Only Watch 慈善拍卖

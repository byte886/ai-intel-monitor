## 陶瓷场景要点（来源：industry-packs §ceramics + 矩阵 v1 §3.3）

- **品类覆盖**：
  - 中华艺术瓷/名窑（景德镇青花·粉彩·颜色釉 / 醴陵釉下五彩 / 汝官哥钧定五大名窑）
  - 中华日用瓷/产业瓷（潮州日用瓷·卫浴出口 / 佛山建筑陶瓷·卫浴）
  - 海外体系：日本有田烧·九谷烧·备前烧 / 欧洲 Meissen·Wedgwood·Limoges / 伊斯兰伊兹尼克陶
  - 古瓷收藏线（五大名窑 + 明清瓷片，拍卖/鉴宝）
  - **陶瓷手串（额外覆盖，2026-10-07 补建）**：青花瓷珠/汝窑珠/钧窑珠/建盏珠/紫砂珠/粉彩珠/瓷烧珠/老瓷片珠手串——茶器衍生 + 文玩佩戴线
- **主阵地**：抖音（开窑/手作/文玩手串直播）；小红书（茶器种草/手串穿搭）；1688（产业带源头珠厂/日用瓷批发）；雅昌艺术网·嘉德·保利（古瓷拍卖成交第一落点）
- **高价值渠道速记**：
  - 展会：**景德镇国际陶瓷博览会**、**醴陵国际陶瓷产业博览会**（2026-09-29~10-03）、**佛山陶博会/CERAMBATH**（第45届 2026-10）、**广交会 140 届**（2026-10）——展会季前后加密监控
  - 拍卖/收藏：**雅昌艺术网**（auction.artron.net 古瓷拍卖图录）、嘉德/保利官网瓷器专场；苏富比/佳士得欧洲瓷器部
  - 内容：抖音"开窑/手作/陶瓷手串直播"、小红书茶器与新中式手串种草、B站瓷器科普
  - 产业带：1688 景德镇/潮州/佛山源头厂；潮州陶瓷产业协会
  - 海外：Instagram（日瓷/欧瓷品牌橱窗）、Pinterest（茶器·瓷器灵感长尾）
  - **陶瓷手串专属源**：抖音文玩手串直播（景德镇雕塑瓷厂/陶溪川摆摊与源头厂号）、小红书手串种草、1688 源头珠厂（陶瓷手链批发价 ¥1.8~1.91 起，200 条起拿档）、文玩电商（得物等）——事实性数据见关键词库"陶瓷手串专组"脚注

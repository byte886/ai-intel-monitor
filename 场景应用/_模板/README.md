# 场景应用 · 行业接入模板

> 新行业接入监控体系时，**复制本目录**为 `场景应用/<行业名>/`，按下面步骤填充。通用渠道/机制（`01~04` 目录）无需改，行业特定内容放本目录。

## 复制后必做清单

1. **README.md**：改行业名、品类覆盖、主阵地、高价值渠道速记（复刻 jewelry 的格式）
2. **关键词库.md**：按行业摘出各平台关键词（参考 jewelry 关键词库的结构：营销词/AI词/品类词/海外组）
3. **每周情报速递模板.md**：复制 jewelry 模板，改行业名与归档路径
4. 建立 `指向<行业>主仓` 指针（如有独立主仓）；无主仓则本目录即行业资产

## 结构要求

```
场景应用/<行业名>/
├── README.md          # 行业场景要点 + 指向主仓/矩阵
├── 关键词库.md        # 各平台关键词组合（营销/AI/品类/海外四组 + 维护规则）
└── 每周情报速递模板.md # 周报产出格式（一、本周发现 二、数据异动 三、海外风向 四、下周选题）
```

## 接入后的维护

- 关键词库：每月复核（删失效词/加新热词），变化标复核时间
- 情报速递：每周一期，命名 `2026-WNN_<行业>情报.md`；每月合并月报
- 渠道矩阵中行业特定部分：随月度渠道规则核对更新

> 模板参考实例：`../jewelry/`（首个场景，2026-10-06 建成）。
